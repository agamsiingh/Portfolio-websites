# 🌐 Personal Portfolio Website

Welcome to my portfolio website repository! This project showcases my personal and professional journey — from education and skills to projects, research, and more.

## 🚀 Live Preview

Check out the live version here: [https://agamsiingh.github.io/Portfolio-websites/](https://agamsiingh.github.io/Portfolio-websites/)

## 🧩 Features

- 🏠 **Home**: Introduction and overview
- 🎓 **Education**: Academic background and achievements
- 💼 **Experience**: Work experience and internships
- 🛠️ **Projects**: Key personal and collaborative projects
- 💻 **Tech Stack**: Skills, tools, and technologies used
- 🎨 **Design**: Creative works and design examples
- 🔬 **Research**: Academic and industry research contributions
- 🌍 **Travel**: Travel experiences and learnings
- 🤝 **References**: Testimonials and recommendations
